# AGENTDIRPRO LAB conventions

## Conventions

1. Work directly on the work-order branch named by the task.
2. Keep public-facing content plain ASCII unless the work order explicitly permits otherwise.
3. Put an identity/provenance header first in generated files where a header is applicable.
4. Put a `SELF-REPORT` block last in generated files where a self-report is applicable.
5. Update self-report blocks when later corrections change the artifact they describe.
6. Do not claim tests or actions that were not actually performed.
